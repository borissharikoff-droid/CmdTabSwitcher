КАК ПОСТАВИТЬ
=============

1. Два клика по «Установить CmdTabSwitcher.pkg» → Продолжить → Установить → пароль.
2. Приложение запустится само и покажет окно с двумя разрешениями
   (Accessibility и Screen Recording). Нажми «Открыть настройки…» и включи
   тумблер напротив CmdTabSwitcher — для каждого из двух. Окно закроется само.
3. Держи Cmd, жми Tab. Всё.


ЕСЛИ macOS НЕ ДАЁТ ОТКРЫТЬ PKG
==============================

Это Gatekeeper: приложение не подписано сертификатом Apple (нет аккаунта
разработчика за $99/год), поэтому первый запуск надо разрешить руками — один раз.

macOS 15 Sequoia и новее:
  1. Два клика по pkg → появится «Apple не может проверить…» / «Не удалось открыть».
     Нажми «Готово» (НЕ «В Корзину»).
  2. Системные настройки → Конфиденциальность и безопасность → прокрути в самый низ,
     раздел «Безопасность»: там будет «…pkg заблокировано» и кнопка «Всё равно открыть».
  3. Нажми её, введи пароль → откроется установщик.

macOS 13–14:
  Правый клик (или Ctrl+клик) по pkg → «Открыть» → в диалоге ещё раз «Открыть».


ВООБЩЕ БЕЗ GATEKEEPER (альтернатива — одна команда в Терминале)
===============================================================

  curl -fsSL https://raw.githubusercontent.com/borissharikoff-droid/CmdTabSwitcher/main/install.sh | bash

Скачает последнюю версию, положит в /Applications и запустит. Никаких диалогов
«не удалось проверить» — у файлов, скачанных curl, нет флага карантина.


ТУМБЛЕРЫ ВКЛЮЧЕНЫ, А CMD+TAB НЕ РАБОТАЕТ
========================================

Значок в строке меню → «Разрешения…» → кнопка «Тумблеры включены, но не работает —
сбросить». Приложение перезапустится и попросит разрешения заново. (Так бывает
после обновления со старых версий 1.0.x — там подпись менялась с каждой сборкой.)
